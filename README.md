## 📖 项目简介
本项目基于沁恒 CH32V307 (RISC-V 架构) 开发板，利用软件 I2C 和 ADC 采集温湿度、气压及 MQ-2 烟雾数据，实时显示于 OLED 屏幕。当空气质量超标时，自动触发蜂鸣器声光报警，并驱动继电器开启排风扇进行排风。

## 🛠️ 硬件架构
* **主控**：CH32V307VCT6
* **传感器**：AHT20 (温湿度), BMP280 (气压), MQ-2 (烟雾)
* **外设**：OLED 显示屏, 继电器模块, 5V 直流风扇, 有源蜂鸣器

## 💡 技术亮点
1. **底层驱动编写**：纯手工编写软件 I2C 时序（使用开漏输出配置），适配多设备挂载总线。
2. **数据防抖**：针对 AHT20 传感器，加入了状态位校验算法，有效拦截乱码数据跳变。
3. **安全隔离供电**：单片机（电脑供电）与执行器（风扇，充电宝供电）采用双电源独立供电，通过继电器进行电气隔离，保障系统高负载运行时的稳定性。

## 🔌 核心引脚分配
* **I2C 总线**：PB6 (SCL), PB7 (SDA)
* **MQ-2 模拟量**：PA0
* **蜂鸣器**：PA1
* **继电器控制**：PA2
